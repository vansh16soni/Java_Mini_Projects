# Java Mini Projects

A collection of Java mini projects, object-oriented programming (OOP) implementations, and practical console applications.

---

## 📂 Projects Overview

### 1. 📚 Library Management System (`java/library`)
A console-based Library Management System demonstrating core Object-Oriented Programming (OOP) principles in Java.

#### ✨ Key Features
- **Polymorphism & Inheritance:** Base class `LibraryItem` extended by `Book`, `Magazine`, and `AudioBook`.
- **Encapsulation & Validation:** Secure state management for catalog items and checkout statuses.
- **Dynamic Inventory Management:** View catalog items, issue and return items with status tracking.
- **Search Functionality:** Case-insensitive keyword search by title.

#### 🚀 How to Run
```bash
# Compile
javac java/library/*.java

# Run
java java.library.LibraryApp
```
